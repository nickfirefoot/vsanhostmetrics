WHAT THIS SOFTWARE DOES

It connects to one vCenter Server over HTTPS using credentials you supply, and
reads performance data from the vSAN Performance Service. It reads only. It
issues no configuration change, and it does not connect to ESXi hosts. A
read-only vCenter account is sufficient and is what is recommended.

The adapter runs as a container on a VCF Operations Cloud Proxy. The container
image is published at ghcr.io/nickfirefoot/vsanhostmetrics and is referenced by
immutable digest, so the image your Cloud Proxy runs is cryptographically
bound to the pack you installed.
